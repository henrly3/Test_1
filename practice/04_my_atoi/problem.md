# 04. my_atoi (오버플로 처리)

표준 라이브러리(`atoi`, `strtol`, `sscanf` 등)를 쓰지 않고 문자열을 `int32_t`로 바꾸세요.

```c
/* 성공 시 1, 실패 시 0. 성공하면 *out 에 값을 저장 */
int my_atoi(const char *s, int32_t *out);
```

규칙:
1. 앞쪽 공백(`' '`, `'\t'`)은 무시합니다.
2. 부호 `+` / `-`는 최대 한 번, 숫자 바로 앞에만 올 수 있습니다.
3. 숫자 뒤에 숫자가 아닌 문자가 나오면 실패입니다. (단, 뒤쪽 공백은 허용)
4. 숫자가 하나도 없으면 실패입니다.
5. `int32_t` 범위(-2147483648 ~ 2147483647)를 벗어나면 실패입니다.
6. `s`가 `NULL`이면 실패입니다.

## 예시

| 입력 | 결과 |
|------|------|
| `"42"` | 성공, 42 |
| `"   -17  "` | 성공, -17 |
| `"+0"` | 성공, 0 |
| `"2147483647"` | 성공, 2147483647 |
| `"-2147483648"` | 성공, -2147483648 |
| `"2147483648"` | 실패 (오버플로) |
| `"12a"` | 실패 |
| `"-"` / `""` / `"+-3"` | 실패 |

## 체크 포인트
- 오버플로를 **곱하기 전에** 검사하세요. `val * 10 + d`를 계산한 뒤 검사하면 이미 UB입니다.
- `-2147483648`은 양수로 먼저 모은 뒤 부호를 붙이면 넘칩니다. 음수 쪽으로 모으거나 `int64_t`를 쓰세요.
