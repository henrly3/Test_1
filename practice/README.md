## 실행 방법

```sh
cd practice
make test     # 모든 풀이를 빌드하고 내장 테스트 실행
make clean
```

각 풀이 파일의 `main()`에 테스트 케이스가 들어 있습니다. 직접 푼 코드로
풀이 함수를 바꿔 넣고 `make test`로 검증해 보세요.

## 준비 팁

- **시간 제한 연습**: 문제당 30~40분 안에 푸는 것을 목표로 하세요.
- **C로도 풀 수 있게**: STL 없이 배열 큐/스택, `qsort`를 쓸 수 있어야 합니다.
- **예외 처리**: 빈 입력, 최댓값/최솟값, 오버플로, 버퍼 꽉 참/비어 있음 같은 경계 조건을 먼저 생각하세요.
- **고정 크기 정수형**: 임베디드 문제에서는 `int` 대신 `uint8_t`, `uint16_t`, `uint32_t`(`<stdint.h>`)를 쓰는 습관을 들이세요.
