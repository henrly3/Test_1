# 05. 레이더 표적 군집 탐지

레이더 화면이 `N x M` 격자로 주어집니다. 각 칸의 값은 신호 세기(0~255)입니다.
신호 세기가 임계값 `T` **이상**인 칸을 "탐지 칸"이라 합니다.
상하좌우로 이어진 탐지 칸들은 하나의 **표적**으로 봅니다.

단, 칸 수가 `K`개 **미만**인 표적은 잡음(clutter)으로 보고 무시합니다.

유효한 표적의 개수와, 각 표적의 크기(칸 수)를 **내림차순**으로 출력하세요.
유효한 표적이 없으면 `0`만 한 줄 출력합니다.

## 입력
```
N M T K          (1 ≤ N, M ≤ 1000, 0 ≤ T ≤ 255, 1 ≤ K ≤ N*M)
N줄에 걸쳐 M개의 정수
```

## 출력
```
표적 개수
크기1 크기2 ...   (내림차순, 공백 구분)
```

## 예시 입력
```
5 6 100 2
120 130   0   0   0 200
  0 110   0  90   0 210
  0   0   0 150   0   0
 99   0 101 160 170   0
  0   0   0   0   0 255
```

## 예시 출력
```
3
4 3 2
```

설명 (좌표는 `(행, 열)`):
- (0,0), (0,1), (1,1) → 크기 3
- (0,5), (1,5) → 크기 2
- (2,3), (3,2), (3,3), (3,4) → 크기 4
- (4,5) → 크기 1, K=2 미만이므로 잡음
- (3,0)=99 는 T=100 미만이라 탐지 칸이 아님

## 체크 포인트
- N·M이 최대 100만이므로 **재귀 DFS는 스택 오버플로** 위험이 있습니다(임베디드에서는 특히). BFS 또는 명시적 스택을 쓰세요.
- `visited` 배열을 따로 두지 말고 원본을 0으로 덮어 메모리를 아낄 수도 있습니다.
- 입력이 많으므로 `ios::sync_with_stdio(false); cin.tie(nullptr);` 또는 `scanf`를 사용하세요.
