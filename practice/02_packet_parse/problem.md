# 02. 센서 패킷 파싱

센서에서 아래 형식의 바이트 스트림이 들어옵니다. 멀티바이트 값은 모두 **빅 엔디안**입니다.

| 오프셋 | 크기 | 필드 | 설명 |
|--------|------|------|------|
| 0 | 1 | STX | 항상 `0x02` |
| 1 | 1 | ID | 센서 ID |
| 2 | 2 | LEN | 페이로드 길이 N (바이트) |
| 4 | N | PAYLOAD | 2바이트 부호 있는 정수(`int16_t`)들의 배열 (N은 짝수) |
| 4+N | 1 | CHK | ID, LEN(2바이트), PAYLOAD 전체를 XOR한 값 |
| 5+N | 1 | ETX | 항상 `0x03` |

다음 함수를 구현하세요.

```c
typedef struct {
    uint8_t id;
    int     count;          /* 샘플 개수 */
    int16_t samples[64];
} Packet;

/* 성공 시 0, 실패 시 음수 에러코드 반환 */
int parse_packet(const uint8_t *buf, int buf_len, Packet *out);
```

에러 코드:
- `-1`: 길이 부족 (헤더/페이로드/트레일러가 `buf_len`을 넘어감)
- `-2`: STX 또는 ETX 불일치
- `-3`: 체크섬 불일치
- `-4`: LEN이 홀수이거나 샘플 수가 64개를 넘음

## 예시

```
입력: 02 07 00 04 00 64 FF 9C 04 03
  ID=7, LEN=4, PAYLOAD = 0x0064(100), 0xFF9C(-100)
  CHK = 07^00^04^00^64^FF^9C = 0x04
결과: 0, id=7, count=2, samples={100, -100}
```

## 체크 포인트
- 빅 엔디안 → 호스트 값: `(buf[i] << 8) | buf[i+1]`
- 부호 있는 16비트 변환: `(int16_t)(uint16_t)...`
- `memcpy`로 구조체에 바로 붓는 방식은 엔디안과 패딩 때문에 위험합니다.
