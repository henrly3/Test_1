# 07. C 언어 개념 퀴즈

임베디드 직무 필기, 코딩테스트 객관식, 기술 면접에 자주 나오는 개념입니다.
답을 먼저 적어 본 뒤 아래 정답을 확인하세요. `check.c`는 일부 답을 실제로 실행해 확인합니다.
(sizeof 관련 답은 일반적인 32/64비트 환경, 4바이트 `int` 기준입니다.)

---

**Q1.** `sizeof(struct A)`와 `sizeof(struct B)`는?
```c
struct A { char c; int i; char d; };
struct B { int i; char c; char d; };
```

**Q2.** 출력은?
```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = (int *)(&arr + 1);
printf("%d %d\n", *(arr + 1), *(p - 1));
```

**Q3.** 출력은?
```c
unsigned int u = 1;
int s = -1;
printf("%s\n", (s < u) ? "less" : "greater");
```

**Q4.** 다음 선언의 의미는?
```c
const int *a;
int * const b;
int (*c)[10];
int *d[10];
void (*e)(int);
```

**Q5.** `volatile`은 언제, 왜 필요한가? 대표적인 경우를 3가지 이상 쓰세요.

**Q6.** 아래 매크로의 문제점과 `SQUARE(a++)`를 호출하면 생기는 문제는?
```c
#define SQUARE(x) x * x
```

**Q7.** 리틀 엔디안 시스템에서 출력은?
```c
uint32_t x = 0x12345678;
uint8_t *p = (uint8_t *)&x;
printf("%02X %02X\n", p[0], p[3]);
```

**Q8.** 함수 안의 `static int cnt = 0;`과 파일 전역 `static int g;`의 차이는?

**Q9.** 다음 코드의 버그는?
```c
char *get_name(void)
{
    char name[16] = "radar";
    return name;
}
```

**Q10.** 출력은?
```c
int x = 5;
printf("%d\n", x++ + ++x);
```

## 정답

**A1.** `A = 12`, `B = 8`.
A는 `c(1) + pad(3) + i(4) + d(1) + pad(3)`입니다. B는 `i(4) + c(1) + d(1) + pad(2)`입니다.
구조체 크기는 가장 큰 멤버 정렬 단위의 배수여야 합니다. 멤버를 큰 것부터 배치하면 메모리를 아낄 수 있습니다.

**A2.** `2 5`.
`&arr`의 타입은 `int (*)[5]`이므로 `&arr + 1`은 배열 전체 크기(20바이트)만큼 뒤를 가리킵니다. `p - 1`은 마지막 원소입니다.

**A3.** `greater`.
`int`와 `unsigned int`를 비교하면 `s`가 unsigned로 변환되어 `0xFFFFFFFF`가 됩니다. 컴파일 옵션 `-Wsign-compare`로 잡을 수 있습니다.

**A4.**
- `a`: const int를 가리키는 포인터입니다. 값은 못 바꾸고 포인터는 바꿀 수 있습니다.
- `b`: int를 가리키는 const 포인터입니다. 포인터는 못 바꾸고 값은 바꿀 수 있습니다.
- `c`: int 10개짜리 배열을 가리키는 포인터입니다.
- `d`: int 포인터 10개짜리 배열입니다.
- `e`: int를 받고 void를 반환하는 함수 포인터입니다.

**A5.** 컴파일러가 값이 바뀌지 않는다고 가정하고 읽기를 레지스터에 캐시하거나 접근을 없애지 못하게 할 때 필요합니다.
1. 메모리 맵 하드웨어 레지스터 (상태 레지스터 폴링)
2. ISR과 메인 루프가 함께 쓰는 변수
3. 멀티태스킹 환경에서 다른 태스크가 바꾸는 변수 (단, `volatile`은 원자성이나 메모리 순서를 보장하지 않습니다)

**A6.** `SQUARE(1 + 2)`는 `1 + 2 * 1 + 2 = 5`로 전개됩니다.
`#define SQUARE(x) ((x) * (x))`처럼 괄호를 쳐야 합니다. 그래도 `SQUARE(a++)`는 `a`를 두 번 증가시키고, 시퀀스 포인트 없이 수정하므로 UB입니다.
`static inline int square(int x)` 함수를 쓰는 것이 안전합니다.

**A7.** `78 12`. 리틀 엔디안은 하위 바이트를 낮은 주소에 저장합니다.

**A8.**
- 함수 안 `static`: 수명은 프로그램 전체이고(초기화 1회) 범위는 함수 안입니다. 호출 사이에 값이 유지됩니다.
- 파일 전역 `static`: 내부 링크(internal linkage)라서 다른 `.c` 파일에서 `extern`으로 접근할 수 없습니다.

**A9.** 지역 배열(스택)의 주소를 반환합니다. 함수가 끝나면 그 메모리는 무효(dangling pointer)가 됩니다.
`static char name[16]`, 호출자가 버퍼를 넘기는 방식, 또는 `malloc`(임베디드에서는 지양)으로 고칩니다.

**A10.** 정의되지 않은 동작(UB)입니다. 시퀀스 포인트 사이에 `x`를 두 번 수정하므로 컴파일러마다 결과가 다를 수 있습니다. "12"라고 답하면 오답입니다.
